# Vital Health

Aplicação web para centralizar o acompanhamento de treinos, alimentação e evolução física em um só lugar.

## Sobre o projeto

Manter hábitos saudáveis e uma rotina de exercícios costuma ser difícil por falta de ferramentas práticas. As informações acabam espalhadas em vários aplicativos ou controles manuais pouco eficientes.

O **Vital Health** surge para resolver isso, reunindo o gerenciamento de treinos, o controle nutricional e as métricas de evolução física em uma interface única e intuitiva.

O desenvolvimento segue práticas de Engenharia de Software e Modelagem Orientada a Objetos com UML. Este documento apresenta a visão geral da solução, com foco em melhorar a experiência do usuário e manter a consistência no acompanhamento da sua saúde.

## Funcionalidades

- Gerenciamento de treinos
- Controle nutricional
- Acompanhamento de métricas de evolução física

## Tecnologias

- HTML
- CSS
- JavaScript
